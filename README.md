## Featured project

### [Node.js DevOps pipeline](https://github.com/Ja-Gia772473/node-native-devops-pipeline)

A Node.js API deployed to AWS Elastic Beanstalk through GitHub Actions. The project demonstrates:

- Continuous integration with Jest, Supertest, ESLint, `npm ci`, and dependency auditing
- Continuous deployment with a versioned application package and Elastic Beanstalk
- GitHub OpenID Connect (OIDC) authentication with temporary AWS credentials
- IAM trust-policy controls for the repository and deployment branch
- Protected `main` branch rules and a documented pull request workflow
